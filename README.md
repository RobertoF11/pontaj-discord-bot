# Pontaj Discord Bot

Bot de pontaj pentru Discord cu comenzi:
/clock-in  
/clock-out  
/pontaj-status  
/pontaj-history  

## Setup local
1. Creeaza `.env`:
```
BOT_TOKEN=TOKENUL_TAU
CLIENT_ID=ID_BOT
```

2. Ruleaza:
```
npm install
npm start
```

## Deploy pe Railway
- Urca repo-ul pe GitHub
- Creeaza serviciu pe Railway
- Adauga variabilele ENV
- Start
